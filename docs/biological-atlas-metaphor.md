## Decision in one line

**The system atlas is microscopic → macroscopic, like cell → organ → body → environment. The visual journey maps growth from intent (atomic) through Nephew (beta) to Avery Goodman (release identity). Nodes shape a story — not random floating particles.**

---

## Intent as the smallest node

Intent is the atomic unit. Like a gamete, it carries dual factors:

| Factor | Meaning in system |
|--------|-------------------|
| **Function** | What the intent does (verb / capability) |
| **Form** | How it is shaped (structure / contract / surface) |

Bootstrap English and Favor claim composition start here. Everything larger is assembled from intent nodes with function and form.

**Visual direction (future UI):**

- Convergence into a single union node, then layered growth.
- Zoom in: kernel, libraries, runtimes, shells.
- Zoom out: machines (MacBook, DGX Spark, DXP6800), forge, GitTalk rooms.
- Shape the graph into a journey body (growth stages), not a random cloud. Obsidian-style edges, with intentional silhouette over time.

Implementation path when built: React + force graph or Three.js; Prefer shaped targets over pure physics scatter.
