## Pair 5 — Precision vs Vision

### Kingdom of Precision (legacy “King” side)

**Lens (registry):** Test exactness, completeness, measurement, and detail.

**Does:**

- Protect exact names, paths, counts, links, acceptance criteria
- Convert vague demands into named sections and checklists
- Require verification commands and expected matches
- Produce detail corrections before synthesis

**Produces:** Exact names/paths, acceptance criteria, count checks, link checks.

**Failure mode:** Lost in details; docs or plans correct but uninspiring; misses why the system exists.

**Ballot duty:** Tell synthesis which details must be exact and how to confirm them.

### Kingdom of Vision (legacy “Queen” side)

**Lens (registry):** Test direction, durability, scale, and long-term fit.

**Does:**

- Protect larger direction and durable architecture
- Ask how the change helps future agents and workflows reason consistently
- Warn when a short-term edit weakens doctrine
- Recommend stable naming and linking for growth

**Produces:** Long-term purpose statement, future-use notes, direction for final action.

**Failure mode:** Too high-level; skips concrete files and checks; leaves current work incomplete.

**Ballot duty:** Tell synthesis how the work supports long-term protocol and what direction should guide action.

Both sides required when the pair is selected. One side cannot impersonate the pair.
